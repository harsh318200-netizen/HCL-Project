DNS Resolution Comparison — source package

Files:
- dns_lookup_demo.sh: safe command-line helper for Kali Linux.
- screenshots/: eight actual terminal screenshots extracted from the supplied report.

Run:
  chmod +x dns_lookup_demo.sh
  ./dns_lookup_demo.sh

The script performs read-only lookups and does not edit /etc/hosts.
For the hosts-file demonstration, follow the report instructions carefully,
then remove the exact test line and verify the original state.
